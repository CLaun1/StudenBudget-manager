# 🎓 StudentBudget-Manager 💰

Une solution complète de gestion de budget conçue pour les étudiants, combinant la puissance de **Power Apps** pour la saisie des données et de **Power BI** pour l'analyse financière.

## 🌟 Présentation du Projet
Ce projet est né d'un besoin concret : simplifier le suivi des dépenses quotidiennes (loyer, courses, loisirs) pour éviter les découverts. Il démontre une maîtrise de la **Power Platform** dans un contexte concret.

### L'écosystème du projet :
1.  **Application Mobile (Power Apps)** : Interface intuitive pour ajouter une dépense en 3 secondes depuis un smartphone.
2.  **Base de données (Excel/CSV)** : Stockage structuré des transactions, catégories et budgets prévisionnels.
3.  **Tableau de Bord (Power BI)** : Visualisation interactive pour analyser la répartition des dépenses.

## 🛠️ Fonctionnalités clés

### 📱 Power Apps (Saisie)
* **Formulaire dynamique** : Ajout rapide de dépenses avec sélection par catégorie et mode de paiement.
* **Historique en temps réel** : Consultation des dernières transactions effectuées.
* **Design Mobile-First** : Utilisable partout, tout le temps.

### 📊 Power BI (Analyse)
* **Répartition par catégorie** : Visualisation via un graphique en anneau pour identifier les plus gros postes de dépense (Logement, Alimentation, etc.).
* **Indicateurs clés (KPIs)** : Cartes affichant le total des dépenses et le budget consommé.
* **Suivi par mode de paiement** : Analyse des habitudes de consommation (Carte vs Espèces).

## 📂 Contenu du dépôt
* `/Gestion de Budget.msapp` : Le fichier source de l'application Power Apps.
* `/Rapport_Budget.pbix` : Le fichier Power BI Desktop.
* `/Donnees/` : Le fichier excel utilisés comme source de données (Transactions, Catégories, Budgets).

---

## 🚀 Installation & Utilisation
1.  **Power Apps** : Importez le fichier `.msapp` dans votre environnement [Power Apps Studio](https://make.powerapps.com).
2.  **Power BI** : Ouvrez le fichier `.pbix` avec Power BI Desktop. Si les liens sont rompus, redirigez la source vers les fichiers excel fournis dans le dossier `/Donnees/`.
